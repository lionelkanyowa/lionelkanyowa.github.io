Journey

Depth first, deadlines second

I spent years in infrastructure learning that shortcuts usually cost more later. Launch School rewards the same instinct: rigorous assessments, mastery over memorization, and a curriculum that expects you to understand ideas instead of simply recognizing the answers. The goal isn't just learning a language—it's learning how to think like an engineer.

Now · In Progress

Ruby Foundations

Learning programming from first principles: variables, control flow, collections, problem solving, and writing solutions from a blank page. The friction is intentional. Working through problems without shortcuts is what builds real understanding.

Next

Core Curriculum

Two tracks in parallel — the server side in Ruby, the browser side in JavaScript — each course assessed before moving on.
